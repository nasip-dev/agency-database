# 🏢 Агентская база недвижимости — план проекта

## 🎯 Цель
Единая веб-база объектов недвижимости для агентства: у каждого объекта своя карточка,
ответственный агент и уникальный ID (`NS-000125`). Работает с телефона и компьютера,
есть быстрый поиск и фильтры.

### ✅ Принятые решения
- Формат — **веб-сайт** (Telegram-бот можно добавить позже)
- **Все агенты видят все данные**, включая телефон хозяина и цену «на руки»
- Агентов — **до 10**, поэтому хватит бесплатного хостинга
- Валюта — **$ или сом** на выбор для каждого объекта

## 1. Что добавлено к исходному ТЗ (и почему)

| # | Улучшение | Зачем |
|---|-----------|-------|
| 1 | **Вход для агентов (логин/пароль) и роли** «Руководитель» и «Агент» | Поле «Агент» заполняется автоматически, никто не может подписаться чужим именем |
| 2 | **Права на изменение**: смотреть все объекты могут все агенты, а редактировать — только свой агент и руководитель | Никто случайно не испортит чужую карточку |
| 3 | **Комиссия считается автоматически**: цена объявления − цена на руки = $3 000 (3,5%) | Разница видна сразу, считать вручную не нужно |
| 4 | **Статус объекта**: Активен / Задаток / Продан / Снят с продажи | Чтобы проданные объекты не мешали в поиске |
| 5 | **Поля зависят от типа объекта**: для участка площадь в **сотках** и без комнат; для квартиры — этаж / этажность | В ТЗ комнаты есть и у участка, а так быть не должно |
| 6 | **Районы — выпадающий список** (с возможностью добавить новый) | Без него «Асанбай», «асанбай» и «Асанбай мкр» будут считаться тремя разными районами, и фильтр не сработает |
| 7 | **Проверка на дубли** по телефону хозяина и адресу | Два агента не заведут один и тот же объект |
| 8 | **Фото объекта** (несколько штук) | Без фото агенту сложно показать объект клиенту |
| 9 | **Кнопка «Скопировать для клиента»** — текст карточки без данных хозяина и цены «на руки» | Сразу отправить в WhatsApp или Telegram |
| 10 | **Дата создания и изменения** плюс история изменений цены | Видно, когда объект добавили и как менялась цена |
| 11 | **Валюта**: $ или сом | В Кыргызстане используют обе |
| 12 | **Экспорт в Excel** | Для отчётов и резервной копии |

ID: формат `NS-` + 6 цифр. Номер выдаёт база данных по порядку. Он **не повторяется и
не переиспользуется** даже после удаления объекта. Удаление «мягкое»: объект уходит в архив.

## 2. Структура карточки (модель данных)

**Объект (Property)**
- `id` — внутренний номер; `code` — `NS-000125` (уникальный)
- `type` — Квартира / Дом / Участок / Коммерческая / Другое
- `rooms` — 1, 2, 3, 4, 5+ (не заполняется для участка)
- `city`, `district` (справочник), `street`, `house`, `apartment`, `landmark`
- `area` — м² (для участка — сотки), `floor`, `totalFloors` (для квартиры)
- `listPrice` — цена объявления, `ownerPrice` — цена хозяину на руки, `currency`
- **`commission`** — вычисляется: `listPrice − ownerPrice`
- `ownerName`, `ownerPhone`
- `notes` — дополнительная информация
- быстрые отметки: ☐ Торг ☐ Документы готовы ☐ Срочно ☐ С мебелью ☐ С ремонтом
- `status`, `agentId`, `createdAt`, `updatedAt`, `archivedAt`
- `photos[]`

**Агент (User)**: имя, телефон, логин, пароль (в виде хэша), роль, активен/отключён.

**История (PriceHistory)**: объект, старая цена, новая цена, кто изменил, когда.

## 3. Экраны

1. **Вход**
2. **Список объектов**: таблица на ПК, карточки на телефоне
   - строка поиска (ID, адрес, улица, имя хозяина)
   - фильтры: тип, комнаты, район, цена от–до, площадь от–до, агент, статус
   - сортировка: новые, цена, площадь
   - фильтр «Мои объекты»
3. **Карточка объекта**: вся информация, фото, комиссия, история цены, кнопки
   «Редактировать», «Скопировать для клиента», «Изменить статус»
4. **Добавить / изменить объект**: форма, поля которой меняются в зависимости от типа
5. **Агенты** (только для руководителя): добавить или отключить агента
6. **Справочники** (только для руководителя): города и районы

---

## 4. Технологии (предложение)

- **Веб-приложение** (адаптивное, работает с телефона и ПК, без установки)
- **Next.js (React) + TypeScript**: интерфейс и сервер в одном проекте
- **База данных**: SQLite для разработки, PostgreSQL на сервере (через Prisma)
- **Хостинг**: Vercel + Neon/Supabase (бесплатный тариф на старте) или свой VPS
- **Фото**: облачное хранилище (Supabase Storage / Cloudinary)
