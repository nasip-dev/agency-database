# 🏢 Агентская база недвижимости

Веб-приложение для агентства: карточки объектов с уникальным ID (`NS-000125`), агенты, поиск и фильтры.
План проекта и этапы описаны в [PLAN.md](PLAN.md).

## Запуск на своём компьютере

Нужен Node.js 20 или новее.

```bash
npm install
npm run db:migrate   # создать базу dev.db
npm run db:seed      # первый руководитель + районы Бишкека
npm run db:demo      # (необязательно) демо-агент «ulugbek» и 8 объектов
npm run dev
```

Откройте http://localhost:3000.

Логин руководителя и пароль задаются в файле `.env` (`ADMIN_LOGIN`, `ADMIN_PASSWORD`).
Образец лежит в `.env.example`. После первого входа смените пароль на странице профиля.

## Роли

- **Руководитель** — добавляет агентов, ведёт список районов, может менять любой объект, выгружает базу в Excel.
- **Агент** — видит все объекты, добавляет свои и меняет только свои.

## Полезные команды

| Команда | Что делает |
|---|---|
| `npm run dev` | запуск в режиме разработки |
| `npm run build` / `npm start` | сборка и запуск в боевом режиме |
| `npm run db:studio` | просмотр базы в браузере (Prisma Studio) |
| `npm run db:migrate` | применить изменения схемы базы |

Перед `db:migrate` остановите `npm run dev`: иначе SQLite-файл может быть занят и миграция зависнет.

Чтобы начать с пустой базой, удалите `dev.db` и папку `uploads`, затем снова выполните `db:migrate` и `db:seed`.

## Фото

Фото сжимаются на сервере (до 1600px, WEBP) и хранятся в папке `uploads/photos` (путь меняется переменной `UPLOAD_DIR`).
Открыть фото можно только после входа. Эту папку, как и базу, нужно включить в резервное копирование.

## Технологии

Next.js 16, React 19, TypeScript, Tailwind CSS 4, Prisma 7 и SQLite. Для сервера планируется PostgreSQL.

## Сервер (Fly.io)

Сайт разворачивается на Fly.io из этого репозитория (`Dockerfile`, `fly.toml`).
База и фото лежат на постоянном диске `/data`; при каждом старте `scripts/start.sh`
применяет миграции и, только при первом запуске, создаёт руководителя и районы.

В панели Fly нужно задать секреты `SESSION_SECRET` и `ADMIN_PASSWORD`
(пароль нужен только для первого запуска — потом его меняют в профиле).
Машина должна быть одна: SQLite не делится между машинами.
